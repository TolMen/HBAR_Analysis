# HBAR_Analysis 📊

> **Un projet personnel pour analyser l'achat et la revente de cryptomonnaies.**  
> --> *Version : [English](README.md)* 📖

## Description

- **HBAR_Analysis** est un programme Python permettant de calculer la valeur d'achat et de revente d'une cryptomonnaie.  
- Initialement conçu pour HBAR, il peut être adapté à d'autres cryptos en modifiant quelques paramètres.  
- Ce projet est un exercice personnel et **n'a aucun but professionnel**.  

---

## Personnalisation

Le programme peut être ajusté pour fonctionner avec d'autres cryptomonnaies. <br>
Voici les modifications à apporter :

1. **Changer la cryptomonnaie analysée**  
   - Modifier l'URL de l'API Binance dans la fonction `valueFunction()`.  
   - Remplacer `HBARUSDT` par le symbole de la cryptomonnaie souhaitée (ex : `BTCUSDT` pour Bitcoin).  

2. **Adapter l'affichage**  
   - Modifier les `print()` pour refléter le nom de la cryptomonnaie choisie.  

3. **Modifier la prévision à long terme** (uniquement dans `ScriptPurchaseHBAR.py`)  
   - Modifier la variable `forecast` pour ajuster l'estimation du prix futur.
